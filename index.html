SENTRIX Beta

A Windows security scanner with real-time protection, launch guard, and the AI Scanner beta three-agent scan mode.

Download for Windows Windows 10/11

Install

  1. Download and extract the ZIP.
  2. Run Install SENTRIX Beta.cmd.
  3. If prompted, install the Microsoft .NET 8 Desktop Runtime and run the installer again.

Real-time protection

Watches common user locations while the app is running.

Launch guard

Checks newly opened programs and can stop critical launches.

AI Scanner beta

Runs three scan agents in parallel for processes, startup entries, and files.
